「論格 ThesisFormatter」隱私權政策

最後更新日期：2026 年 7 月 27 日

感謝您使用「論格 ThesisFormatter」（以下簡稱「本應用程式」）。我們極度重視您的個人隱私與學術研究數據安全。本隱私權政策旨在說明本應用程式如何處理您的個人資料與論文檔案。

核心隱私承諾：100% 本機優先（Local-First）
本應用程式採本機架構設計，您的論文正文、數據與導出檔案完全儲存於您的 Mac 電腦本機端，絕不上傳至任何雲端伺服器。

1. 資料蒐集與使用說明

本應用程式遵循「資料最小化」與「零收集」原則：

  • 個人身份資料：我們不蒐集您的姓名、電子郵件地址、電話號碼、IP 位址或任何個人可識別資訊（PII）。
  • 論文與文件數據：我們不讀取、不傳送、亦不儲存您論文內容以外的任何個人隱私資訊。論文內容僅在您的 Mac 本機記憶體與暫存區中進行格式排版與結構解析。
  • 追蹤與分析：本應用程式不包含任何第三方追蹤 SDK、廣告識別碼或使用者行為分析工具。

2. 本機檔案存取權限（macOS 沙盒機制）

本應用程式嚴格遵守 macOS App Sandbox（沙盒）安全規範：

  • 檔案存取權限：僅在您透過檔案選擇器（File Picker）或拖放功能授權時，方能存取您指定選取的論文草稿（.docx, .pdf, .txt）與格式規範檔案。
  • 暫存檔處理：所有排版過程中產生的臨時解析檔案均存放在 macOS 沙盒指定的本機暫存目錄中，並在轉換完成或應用程式關閉後由系統安全機制管控。

3. 選用性網路服務（Optional Network Features）

本應用程式的核心排版功能可完全離線運作。唯有在您主動開啟特定功能時，會進行極最小化的發起請求：

  • DOI / ISBN 輔助檢索功能：若您在設定中主動勾選「補齊 DOI / ISBN 建議」，應用程式會將您參考文獻中的公開書目字串，透過加密 HTTPS 連線傳送至公開學術資料庫（如 Crossref API 或 Open Library API）進行資料比對。
  • 網路請求範圍：此請求僅包含公開之書目後設資料（Metadata），絕不包含您的論文正文、摘要或個人資訊。若關閉此功能，本應用程式將完全不發起任何網路連線。

4. 第三方資料共享

由於我們不蒐集您的任何資料，因此我們絕不可能將您的任何個人資訊或論文數據出售、租賃、交換或共享給任何第三方。

5. 兒童隱私（Children's Privacy）

本應用程式為面向學術研究者之專業工具，不針對 13 歲以下兒童設計，亦不會故意蒐集兒童的任何個人資料。

6. 隱私權政策之修改

我們可能會不定期更新本隱私權政策。任何變更均會發布於此網頁，並更新頁首之「最後更新日期」。

Privacy Policy - ThesisFormatter

Last Updated: July 27, 2026

Thank you for using "ThesisFormatter" (hereinafter referred to as "the Application"). We place the utmost importance on your personal privacy and academic research data security. This Privacy Policy explains how the Application handles your personal data and manuscript files.

Core Privacy Commitment: 100% Local-First
The Application is built with a local-first architecture. Your manuscript text, data, and exported files are processed and stored entirely on your local Mac computer and are NEVER uploaded to any cloud server.

1. Data Collection and Usage

The Application adheres to the principles of "Data Minimization" and "Zero Collection":

  • Personally Identifiable Information (PII): We do not collect your name, email address, phone number, IP address, or any other PII.
  • Manuscript and Document Data: We do not read, transmit, or store any personal data beyond your document content. Your manuscript is processed solely in local memory and temporary directories on your Mac for formatting purposes.
  • Tracking and Analytics: The Application contains no third-party tracking SDKs, advertising IDs, or user analytics tools.

2. Local File Access & macOS Sandbox

The Application strictly complies with macOS App Sandbox security guidelines:

  • File Access Permission: Access is granted only when you explicitly select manuscript drafts (.docx, .pdf, .txt) or guideline specifications using the native file picker or drag-and-drop mechanism.
  • Temporary File Handling: All intermediate parsing files generated during formatting are stored in the designated sandbox temporary directory and managed securely by macOS system policies upon completion or app exit.

3. Optional Network Features

Core formatting features operate completely offline. Minimal network requests are issued only when you explicitly enable specific features:

  • DOI / ISBN Lookup Feature: If you manually enable "Suggest DOI / ISBN Completion" in settings, the Application sends public bibliographic metadata strings over encrypted HTTPS to open academic databases (such as Crossref API or Open Library API) for verification.
  • Scope of Requests: Requests contain ONLY public bibliographic metadata, never your manuscript body, abstract, or personal information. If disabled, no network connections will be initiated.

4. Third-Party Data Sharing

Since we do not collect any user data, we will never sell, rent, exchange, or share your personal information or manuscript data with any third party.

5. Children's Privacy

The Application is a professional tool for academic researchers and is not designed for children under the age of 13. We do not knowingly collect personal data from children.

6. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated "Last Updated" date.
