「論格 ThesisFormatter」隱私權政策

最後更新日期：2026 年 7 月 27 日

感謝您使用「論格 ThesisFormatter」（以下簡稱「本應用程式」）。我們極度重視您的個人隱私與學術研究數據安全。本隱私權政策旨在說明本應用程式如何處理您的個人資料與論文檔案。

核心隱私承諾：100% 本機優先（Local-First）
本應用程式採本機架構設計，您的論文正文、數據與導出檔案完全儲存於您的 Mac 電腦本機端，絕不上傳至任何雲端伺服器。

1. 資料蒐集與使用說明

本應用程式遵循「資料最小化」與「零收集」原則：

  • 個人身份資料：我們不蒐集您的姓名、電子郵件地址、電話號碼、IP 位址或任何個人可識別資訊（PII）。
  • 論文與文件數據：我們不讀取、不傳送、亦不儲存您論文內容以外的任何個人隱私資訊。論文內容僅在您的 Mac 本機記憶體與暫存區中進行格式排版與結構解析。
  • 追蹤與分析：本應用程式不包含任何第三方追蹤 SDK、廣告識別碼或使用者行為分析工具。

2. 本機檔案存取權限（macOS 沙盒機制）

本應用程式嚴格遵守 macOS App Sandbox（沙盒）安全規範：

  • 檔案存取權限：僅在您透過檔案選擇器（File Picker）或拖放功能授權時，方能存取您指定選取的論文草稿（.docx, .pdf, .txt）與格式規範檔案。
  • 暫存檔處理：所有排版過程中產生的臨時解析檔案均存放在 macOS 沙盒指定的本機暫存目錄中，並在轉換完成或應用程式關閉後由系統安全機制管控。

3. 選用性網路服務（Optional Network Features）

本應用程式的核心排版功能可完全離線運作。唯有在您主動開啟特定功能時，會進行極最小化的發起請求：

  • DOI / ISBN 輔助檢索功能：若您在設定中主動勾選「補齊 DOI / ISBN 建議」，應用程式會將您參考文獻中的公開書目字串，透過加密 HTTPS 連線傳送至公開學術資料庫（如 Crossref API 或 Open Library API）進行資料比對。
  • 網路請求範圍：此請求僅包含公開之書目後設資料（Metadata），絕不包含您的論文正文、摘要或個人資訊。若關閉此功能，本應用程式將完全不發起任何網路連線。

4. 第三方資料共享

由於我們不蒐集您的任何資料，因此我們絕不可能將您的任何個人資訊或論文數據出售、租賃、交換或共享給任何第三方。

5. 兒童隱私（Children's Privacy）

本應用程式為面向學術研究者之專業工具，不針對 13 歲以下兒童設計，亦不會故意蒐集兒童的任何個人資料。

6. 隱私權政策之修改

我們可能會不定期更新本隱私權政策。任何變更均會發布於此網頁，並更新頁首之「最後更新日期」。
